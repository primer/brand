## Examples

### Default

```jsx live
<FormControl>
  <FormControl.Label>Enable notifications</FormControl.Label>
  <ToggleSwitch />
</FormControl>
```

### Uncontrolled

`defaultChecked` sets the initial value. `onChange` receives the next boolean value, not a native change event.

```jsx live
<FormControl>
  <FormControl.Label>Automatically watch repositories</FormControl.Label>
  <ToggleSwitch defaultChecked />
</FormControl>
```

### Controlled

```jsx filename="noinline"
function Example() {
  const [checked, setChecked] = React.useState(false)
  return (
    <FormControl>
      <FormControl.Label>Automatically watch repositories</FormControl.Label>
      <ToggleSwitch checked={checked} onChange={setChecked} />
    </FormControl>
  )
}

render(Example)
```

### Status label

ToggleSwitch shows On/Off status text before the track by default, increasing the control width. Use `statusLabelPosition` to move it after the track, `statusLabelOn` and `statusLabelOff` to localize or reword it, or `hasStatusLabel={false}` to keep the previous width when nearby text already shows the state.

Custom status text supplements the setting label; it does not replace it. Screen readers always announce the state as on or off, so the setting label must make sense with on and off. For example, use "Make repository public" rather than "Repository visibility" with "Public" and "Private" status text.

```jsx live
<Stack>
  <FormControl>
    <FormControl.Label>Status label at end</FormControl.Label>
    <ToggleSwitch statusLabelPosition="end" defaultChecked />
  </FormControl>
  <FormControl>
    <FormControl.Label>Custom status labels</FormControl.Label>
    <ToggleSwitch statusLabelOn="Enabled" statusLabelOff="Disabled" />
  </FormControl>
  <FormControl>
    <FormControl.Label>Without status label</FormControl.Label>
    <ToggleSwitch hasStatusLabel={false} />
  </FormControl>
</Stack>
```

### Disabled

## Component Props

| Name                  | Type                                         | Default     | Description                                                                           |
| --------------------- | -------------------------------------------- | ----------- | ------------------------------------------------------------------------------------- |
| `checked`             | `boolean`                                    |             | Controlled on/off value.                                                              |
| `defaultChecked`      | `boolean`                                    | `false`     | Initial uncontrolled value.                                                           |
| `onChange`            | `(checked: boolean) => void`                 |             | Called once per accepted activation with the next value.                              |
| `onClick`             | `React.MouseEventHandler<HTMLButtonElement>` |             | Activation callback receiving the button event.                                       |
| `disabled`            | `boolean`                                    | `false`     | Blocks activation while retaining keyboard focusability.                              |
| `loading`             | `boolean`                                    | `false`     | Displays pending feedback and exposes `aria-busy` without blocking interaction.       |
| `size`                | `'small' \| 'medium'`                        | `'medium'`  | Alternative sizes.                                                                    |
| `loadingLabel`        | `string`                                     | `'Loading'` | Localized loading announcement.                                                       |
| `loadingLabelDelay`   | `number`                                     | `2000`      | Announcement delay in milliseconds.                                                   |
| `spinnerPosition`     | `'start' \| 'end'`                           | `'end'`     | Indicator placement beside the switch when no visible FormControl label is available. |
| `hasStatusLabel`      | `boolean`                                    | `true`      | Shows visible On/Off status text beside the track.                                    |
| `statusLabelPosition` | `'start' \| 'end'`                           | `'start'`   | Status text placement relative to the track.                                          |
| `statusLabelOn`       | `string`                                     | `'On'`      | Status text for the on state. Custom text also describes the switch.                  |
| `statusLabelOff`      | `string`                                     | `'Off'`     | Status text for the off state. Custom text also describes the switch.                 |
| `aria-label`          | `string`                                     |             | Explicit accessible name matching equivalent visible labeling.                        |
| `aria-labelledby`     | `string`                                     |             | IDs of visible labeling elements.                                                     |
| `aria-describedby`    | `string`                                     |             | Description IDs, combined with status, FormControl, and loading descriptions.         |
| `aria-invalid`        | React ARIA attribute                         |             | Validation state of the switch button.                                                |
| `ref`                 | `React.Ref<HTMLButtonElement>`               |             | Ref for the focusable button.                                                         |
| `className`           | `string`                                     |             | Class applied to the component wrapper.                                               |
| `data-testid`         | `string`                                     |             | Test ID applied to the component wrapper.                                             |

Other standard button attributes, including `aria-controls`, `tabIndex`, keyboard handlers, and `style`, apply to the switch button.

## Accessibility

The switch communicates its state through visible On/Off status text, thumb position, and an I/O symbol in the exposed track: a line means on and a circle means off. These cues remain visible in both sizes, light and dark modes, and forced-colors mode. The status text and symbols supplement color and do not change the switch's accessible name.

The status text is part of the switch's click target. The default On/Off text is hidden from assistive technology, which already announces the state through `aria-checked`. When `statusLabelOn` or `statusLabelOff` changes the text, the current text becomes the switch's description, so screen readers announce it after the state, for example "Make repository public, switch, off, Private". Most screen readers announce only the new state after a toggle and read the updated description when focus returns to the switch. Translated On/Off text also becomes a description, which repeats the state in that language. Both labels reserve the same width, so toggling does not shift the layout. Keep `hasStatusLabel` enabled unless the surrounding interface already shows the state in text.

The switch exposes its state to assistive technology through `role="switch"` and `aria-checked`. Provide a descriptive visible label with `FormControl.Label` or `aria-labelledby`; the status text and symbols do not replace the setting label.

The default track border, state symbols, and enabled thumb meet the 3:1 non-text contrast requirement against the track and default canvas in light and dark modes. ToggleSwitch uses existing Brand palette colors without changing shared palette tokens. Recheck contrast when overriding its colors or placing it on a custom background.
