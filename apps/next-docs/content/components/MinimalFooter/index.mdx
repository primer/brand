import {MinimalFooterChildrenProp} from './react'

```js
import {MinimalFooter} from '@primer/react-brand'
```

## Structure and ownership

`MinimalFooter` renders recognized content in this order:

1. optional `MinimalFooter.Footnotes`
2. a top row with the GitHub logomark and optional `MinimalFooter.BackToTop`
3. optional consumer-owned `MinimalFooter.Content`
4. a bottom region with the copyright statement, `MinimalFooter.Link` children, and social links

The default footer includes only the GitHub logomark, the current-year copyright statement, and the supported social links. Footnotes, content, footer links, and Back to top are opt-in.

`MinimalFooter.Link` is the only footer-link child API and always renders in the bottom region. Top navigation is not supported in this iteration and should not be recreated through `MinimalFooter.Content`; render page navigation outside `MinimalFooter`.

Existing props remain source-compatible, but the footer's visual output and DOM structure have changed. Update snapshots and any descendant or DOM selectors that depend on the previous structure.

## Examples

### Default

```jsx live
<MinimalFooter />
```

### Footer links

Use up to five `MinimalFooter.Link` children for the single link collection in the bottom region. Links can render as anchors or buttons.

```jsx live
<MinimalFooter>
  <MinimalFooter.Link href="https://github.com/organizations/enterprise_plan">Try GitHub for free</MinimalFooter.Link>
  <MinimalFooter.Link href="https://github.com/enterprise">Enterprise</MinimalFooter.Link>
  <MinimalFooter.Link href="https://github.com/enterprise/contact">Email us</MinimalFooter.Link>
</MinimalFooter>
```

### Footnotes

```jsx live
<MinimalFooter>
  <MinimalFooter.Footnotes>
    <Text>
      <sup>1</sup>By signing up, GitHub may use your information to personalize and measure the effectiveness of
      enterprise business ads, including those you see off of GitHub, promotional communications or marketing you
      receive related to the Enterprise Marketing Pages. We will send you relevant emails and promotional information
      based on your GitHub profile and any additional information provided in the sign-up form. If you change your mind,
      you can unsubscribe at any time (an unsubscribe link is provided in every email). For more information on how
      GitHub uses your personal information, please see the{' '}
      <InlineLink
        href="https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement"
        target="_blank"
      >
        GitHub Privacy Statement
      </InlineLink>
      .
    </Text>
  </MinimalFooter.Footnotes>
</MinimalFooter>
```

### Footer social links

`MinimalFooter` renders all supported social links in the bottom region by default. Remove them by passing `socialLinks={false}`, or pass an array of valid social links to filter and reorder the default list.

```jsx live
<Stack>
  Hide all social links:
  <MinimalFooter socialLinks={false} />
  <br />
  Only show GitHub social link:
  <MinimalFooter socialLinks={['github']} />
</Stack>
```

### Custom content

Use `MinimalFooter.Content` to render an opt-in slot between the top row and the bottom region. `MinimalFooter` only positions the slot in the layout; the consumer owns everything rendered inside it, including its internal layout. Only the first `MinimalFooter.Content` child is rendered if more than one is provided. Use `Content` for page-specific controls or information such as a language selector, theme toggle, or status indicator, not to recreate top navigation.

```jsx live
<MinimalFooter>
  <MinimalFooter.Content>
    <Stack direction="horizontal" gap="condensed" padding="none">
      <Text size="200" variant="muted">
        Status:
      </Text>
      <InlineLink href="https://www.githubstatus.com" size="200">
        All systems operational
      </InlineLink>
    </Stack>
  </MinimalFooter.Content>
</MinimalFooter>
```

### Back to top

Use `MinimalFooter.BackToTop` to opt into a control in the top row that scrolls the document back to the top. It is never rendered unless it is explicitly included as a child, and, like the other single-instance children, only the first instance is recognized when more than one is provided. Supply a localized label through `children`.

After keyboard activation, focus moves to the first `<main>` element so the next Tab continues from the top of the page. The component temporarily makes the destination programmatically focusable when needed. Use `focusTargetId` to identify a different semantic top-of-page destination. If the specified element is missing, the component warns in development rather than silently choosing another target. Pointer activation scrolls without moving focus.

```jsx live
<MinimalFooter socialLinks={false}>
  <MinimalFooter.BackToTop>Back to top</MinimalFooter.BackToTop>
</MinimalFooter>
```

`children` supplies the required visible and accessible label:

```jsx live
<MinimalFooter socialLinks={false}>
  <MinimalFooter.BackToTop>Retour en haut</MinimalFooter.BackToTop>
</MinimalFooter>
```

All other props - including ARIA and `data-*` attributes - forward to the underlying `<button>`, consistent with `Button`'s prop-forwarding behavior.

An `onClick` handler always runs before the built-in behavior. Call `event.preventDefault()` inside it to cancel scrolling and focus transfer, taking full ownership of the interaction:

```jsx live
<MinimalFooter socialLinks={false}>
  <MinimalFooter.BackToTop
    onClick={event => {
      // Custom handling runs first...
      console.log('Scrolling to top')
      // ...call event.preventDefault() to skip the built-in scroll entirely.
      event.preventDefault()
    }}
  >
    Back to top
  </MinimalFooter.BackToTop>
</MinimalFooter>
```

Use `scrollBehavior` to customize the DOM [scroll behavior](https://developer.mozilla.org/en-US/docs/Web/API/Element/scroll#behavior) (`'auto'`, `'instant'`, or `'smooth'`) used when the built-in scroll runs, which defaults to `smooth`:

```jsx live
<MinimalFooter socialLinks={false}>
  <MinimalFooter.BackToTop scrollBehavior="auto">Back to top</MinimalFooter.BackToTop>
</MinimalFooter>
```

<Note>

When the user prefers reduced motion, the built-in scroll always uses the explicitly non-animated `behavior: 'instant'`, regardless of `scrollBehavior`. This prevents root-level smooth scrolling from overriding the reduced-motion behavior.

</Note>

## Component props

### MinimalFooter

| Name                 | Type                                                                                                                |                                        Default                                        | Description                                                   |
| :------------------- | :------------------------------------------------------------------------------------------------------------------ | :-----------------------------------------------------------------------------------: | :------------------------------------------------------------ |
| `className`          | `string`                                                                                                            |                                                                                       | Sets a custom class on the root element                       |
| `children`           | <MinimalFooterChildrenProp />                                                                                       |                                      `undefined`                                      | Valid child components                                        |
| `copyrightStatement` | `string` \| `ReactElement`                                                                                          |                        Current-year GitHub copyright statement                        | The copyright statement displayed in the bottom region.       |
| `logoHref`           | `string`                                                                                                            |                                `'https://github.com'`                                 | The href for the GitHub logomark.                             |
| `socialLinks`        | `Array<'x' \| 'github' \| 'linkedin' \| 'youtube' \| 'facebook' \| 'twitch' \| 'tiktok' \| 'instagram'>` \| `false` | `['x', 'github', 'linkedin', 'youtube', 'facebook', 'twitch', 'tiktok', 'instagram']` | Ordered subset of social links, or `false` to hide all links. |

### MinimalFooter.Link

| Name       | Type              |   Default   | Description                           |
| :--------- | :---------------- | :---------: | :------------------------------------ |
| `as`       | `'a'`, `'button'` |    `'a'`    | Applies the underlying HTML element   |
| `children` | `string`          | `undefined` | Label for a link in the bottom region |

### MinimalFooter.Footnotes

| Name       | Type         |   Default   | Description                                                           |
| :--------- | :----------- | :---------: | :-------------------------------------------------------------------- |
| `children` | ReactElement | `undefined` | Use Primer Brand `Text` components to benefit from inherited styling. |

### MinimalFooter.Content

| Name        | Type        |   Default   | Description                                                                                                         |
| :---------- | :---------- | :---------: | :------------------------------------------------------------------------------------------------------------------ |
| `className` | `string`    | `undefined` | Sets a custom class on the root element                                                                             |
| `children`  | `ReactNode` | `undefined` | Consumer-owned content. `MinimalFooter` only positions this slot in the layout; it does not impose internal layout. |

All other props, including ARIA and `data-*` attributes, forward to the underlying `<section>` element.

### MinimalFooter.BackToTop

| Name             | Type                                                 |   Default   | Description                                                                                                                                                                                                                         |
| :--------------- | :--------------------------------------------------- | :---------: | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `focusTargetId`  | `string`                                             | `undefined` | ID of the semantic top-of-page element that receives focus after keyboard activation. Defaults to the first `<main>` element.                                                                                                       |
| `onClick`        | `MouseEventHandler`                                  | `undefined` | Runs before the built-in behavior. Call `event.preventDefault()` to cancel scrolling and focus transfer.                                                                                                                            |
| `scrollBehavior` | `ScrollBehavior` (`'auto'`, `'instant'`, `'smooth'`) | `'smooth'`  | The DOM [scroll behavior](https://developer.mozilla.org/en-US/docs/Web/API/Element/scroll#behavior) used when the user does not prefer reduced motion. Reduced motion always uses the explicitly non-animated `'instant'` behavior. |

All other props, including ARIA and `data-*` attributes, forward to the underlying `<button>`.
