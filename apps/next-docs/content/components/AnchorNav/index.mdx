## Examples

<Note>

`AnchorNav` is designed to fix to the top of the viewport, and requires markup outside of the scope of the component to behave correctly.

Please refer to our [Storybook examples](https://primer.style/brand/storybook/?path=/story/components-anchornav--playground) to see the component in a full-screen context as originally intended.

</Note>

### More links

`AnchorNav` implementations on wide viewports with up to `9` links, will automatically move into an overflow menu if space is limited.

```jsx live
<div style={{position: 'relative', overflowX: 'scroll', width: '100%', contain: 'layout', minHeight: 360}}>
  <AnchorNav>
    <AnchorNav.Link href="#more-links-overview">Overview</AnchorNav.Link>
    <AnchorNav.Link href="#more-links-supply-chain">Software supply chain security</AnchorNav.Link>
```

### Localized menu labels

Internal `AnchorNav` labels, such as the navigation landmark name and the **More** button, are rendered in English by default. Use `menuLabels` to localize them. An `aria-label` on `AnchorNav` takes precedence over `menuLabels.navigationLabel`.

```jsx live
<div style={{position: 'relative', overflowX: 'scroll', width: '100%', contain: 'layout', minHeight: 360}}>
  <AnchorNav
    menuLabels={{
      activeLabel: 'Menú de navegación de anclaje. Seleccionado actualmente:',
      navigationLabel: 'Navegación de anclaje',
      overflowMenuLabel: 'Más',
    }}
  >
    <AnchorNav.Link href="#localized-overview">Descripción general</AnchorNav.Link>
    <AnchorNav.Link href="#localized-features">Funcionalidades</AnchorNav.Link>
    <AnchorNav.Link href="#localized-security">Seguridad</AnchorNav.Link>
    <AnchorNav.Link href="#localized-integrations">Integraciones</AnchorNav.Link>
    <AnchorNav.Link href="#localized-pricing">Precios</AnchorNav.Link>
    <AnchorNav.Link href="#localized-customers">Clientes</AnchorNav.Link>
    <AnchorNav.Link href="#localized-resources">Recursos</AnchorNav.Link>
    <AnchorNav.Link href="#localized-support">Soporte</AnchorNav.Link>
    <AnchorNav.Link href="#localized-faq">Preguntas frecuentes</AnchorNav.Link>
    <AnchorNav.Action href="#">Registrarse</AnchorNav.Action>
  </AnchorNav>
</div>
```

## Component props

### AnchorNav <Label>Required</Label>

| Name              | Type                           |    Default     | Description                                             |
| :---------------- | :----------------------------- | :------------: | :------------------------------------------------------ |
| `children`        | <AnchorNavChildrenProp />      |                | Up to nine `AnchorNav.Link` and one `AnchorNav.Action`  |
| `className`       | `string`                       |                | Sets a custom class                                     |
| `hideUntilSticky` | `boolean`                      |    `false`     | When true, the anchor nav will hide until it is sticky. |
| `id`              | `string`                       |                | Sets a custom id                                        |
| `menuLabels`      | `Partial<AnchorNavMenuLabels>` | English labels | Customizes the labels that `AnchorNav` generates        |
| `ref`             | `React.RefObject`              |                | Forward a Ref to the underlying DOM node                |

`AnchorNavMenuLabels` is exported from `@primer/react-brand`.

#### Menu labels

| Field               | Type     | English default                               | Purpose                                                                |
| :------------------ | :------- | :-------------------------------------------- | :--------------------------------------------------------------------- |
| `activeLabel`       | `string` | `Anchor navigation menu. Currently selected:` | Announced before the current link label on the narrow menu button      |
| `navigationLabel`   | `string` | `Anchored navigation`                         | Accessible name for the navigation landmark. `aria-label` overrides it |
| `overflowMenuLabel` | `string` | `More`                                        | Visible and accessible label for the wide overflow menu                |

### AnchorNav.Link <Label>Required</Label>

`AnchorNav.Link` are anchor links that feature in the menubar

| Name        | Type              | Default | Description                                         |
| :---------- | :---------------- | :-----: | :-------------------------------------------------- |
| `children`  | `string`          |         | Required. Label text                                |
| `className` | `string`          |         | Applies a custom class                              |
| `href`      | `string`          |         | Required. Local identifier for the anchored element |
| `id`        | `string`          |         | Sets a custom id                                    |
| `ref`       | `React.RefObject` |         | Forward a Ref to the underlying DOM node            |

Additional props can be passed to the `<a>` element. [See MDN for a list of props](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/a#attributes) accepted by the `<anchor>` element.

### AnchorNav.Action

`AnchorNav.Action` is the call to action for the AnchorNav. It always uses the small button size.

| Name        | Type              |   Default   | Description                                         |
| :---------- | :---------------- | :---------: | :-------------------------------------------------- |
| `children`  | `string`          |             | Required. Label text                                |
| `className` | `string`          |             | Applies a custom class                              |
| `href`      | `string`          |             | Required. Local identifier for the anchored element |
| `id`        | `string`          |             | Sets a custom id                                    |
| `ref`       | `React.RefObject` |             | Forward a Ref to the underlying DOM node            |
| `variant`   | `string`          | `secondary` | Sets the [Button](/components/Button) variant       |

Additional props can be passed to the `<a>` element. Refer to [Button](/components/Button) for more details or [MDN for a list of props](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/a#attributes) accepted by the `<anchor>` element.
